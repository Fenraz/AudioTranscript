# АудиоТранскрипт

Приложение для локальной транскрибации аудио на Windows 10/11 x64.
Интерфейс написан на C# / Windows Forms, распознавание выполняется Python-движком
на базе faster-whisper и CTranslate2 с моделью Whisper medium.
Аудио обрабатывается на компьютере без API и отправки записей на сервер.

## Возможности

- Очередь из нескольких файлов и перетаскивание в окно.
- Выбор языка, папки результатов и подсказок с именами и терминами.
- Текст с таймкодами и субтитры SRT.
- Прогресс, остановка и сохранение частичного результата.
- Сохранение существующих результатов при повторной обработке.

## Содержимое репозитория

- `source/AudioTranscript.cs` — интерфейс приложения.
- `source/engine.py` — движок распознавания.
- `source/requirements-build.txt` — зависимости для сборки.
- [Инструкция сборки](source/README.md).
- [Инструкция пользователя](<Прочитать перед запуском.txt>).

Готовые EXE, зависимости движка и веса модели не хранятся в Git.
Аудиозаписи, транскрипты, секреты и контекст чата также исключены через `.gitignore`.

## Запуск и сборка

Для запуска готовой сборки рядом должны находиться:

```text
AudioTranscript/
  АудиоТранскрипт.exe
  engine/
    engine.exe
    ...
  model/
    model.bin
    config.json
    tokenizer.json
    vocabulary.txt
```

Клонирование репозитория само по себе не устанавливает готовую программу.
Для сборки нужны Windows, Python 3.12 x64 и компилятор .NET Framework.
Команды сборки и необходимая поправка совместимости PyAV описаны в
[source/README.md](source/README.md). Выполняйте команды оттуда из папки `source`,
затем перенесите готовые EXE и папку движка в структуру, показанную выше.
Веса модели берутся из `Systran/faster-whisper-medium`.

## Ограничения

Распознавание выполняется на CPU и может занимать длительное время.
Текст и таймкоды требуют проверки; разделение по спикерам не предусмотрено.
Сторонние библиотеки и модель сохраняют собственные лицензии.
